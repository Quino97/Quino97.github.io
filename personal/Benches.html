Overview

Home Woodworking Project

The goal was to create functional, durable benches with a clean aesthetic that would complement the home environment. The project explored modular component design, joinery selection, and practical iteration during the build process.

Key Contributions & Learnings

  • Designing for comfort, durability, and clean aesthetics
  • Material selection — wood types, finishes, and hardware
  • Cutting, assembly, and joinery techniques
  • Modular and scalable component design
  • Practical problem-solving and iteration during build
  • Process documentation and visual presentation
