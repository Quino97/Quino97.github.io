DCMD Desalination Product

A Direct Contact Membrane Distillation module designed to desalinate water for residential use, improving permeate production by minimising cross-flow and temperature polarisation.

About the Project

A direct contact membrane module system that desalinates water, intended for use in personal homes in Saudi Arabia. The project involved developing a module that improves permeate production by minimising cross-flow and temperature polarisation, as well as creating a modular membrane system allowing for variable permeate production based on feed availability.

Client information and further project details are confidential.
