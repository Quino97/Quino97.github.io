Intelligent Grinding System (IGS)

A MATLAB application combined with real-time DAQ integration to optimise grinding process parameters — minimising residual stress, burn, wheel wear and cycle time.

Overview

MATLAB Process Optimisation Application

The IGS application interfaces with DeweSoft DAQ hardware to acquire live force and temperature data, converting it to meaningful process metrics: residual stress, burn information, and wheel wear.

A Microsoft Access SQL database stores workpiece and process data, with a custom GUI for data entry and querying. The system was validated against real datasets and handed over for live implementation.

What I Did

  • Research into grinding process physics
  • Process design and mathematical modelling
  • MATLAB application development (GUI + logic)
  • MATLAB physics model implementation
  • SQL database design in Microsoft Access
  • Database GUI development
  • Validation against experimental datasets
